# Discord 티켓·정보수집 봇

티켓 생성/종료와 서버별 정보 수집 기능만 제공하는 Discord 봇입니다.

## Render 배포

- **Build Command:** `npm install`
- **Start Command:** `npm start`
- **Health Check Path:** `/health`
- 환경변수 `TOKEN`에 Discord 봇 토큰을 등록합니다.

`/health` 또는 `/`에 HTTP 200 JSON 응답을 제공하므로 Render 웹 서비스 헬스체크에 사용할 수 있습니다.

## 제공 명령어

- `/setup`: 정보 수집 채널과 질문 설정
- `/설정수정`: 기존 정보 수집 질문 수정
- `/정보수집`: 정보 제출 메시지 게시
- `/티켓게시`: 티켓 생성 메시지 게시
- `/정보삭제`: 특정 사용자의 제출 정보 삭제
- `/정보전체삭제`: 서버의 제출 정보 전체 삭제
- `/reset`: 서버 설정 및 제출 정보 초기화
- `/설정확인`: 현재 정보 수집 설정 확인
- `/정보현황`: 제출 정보 및 열린 티켓 현황 확인
- `/자동저장`: 현재 채널에서 상담 제목과 세부사항을 입력해 저장
- `/저장정보`: 현재 채널에 저장된 상담 기록 조회

상담 기록은 기존 SQLite 데이터베이스의 `ticket_summaries` 테이블에 서버·채널별로 저장됩니다.
데이터 백업 및 복구 명령어와 모듈은 제거되어 있습니다.
